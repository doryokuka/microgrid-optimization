
# 微网购电策略：滚动预测与多阶段优化

本项目研究在负荷、光伏发电及电价信息逐步更新的条件下，如何通过预测与滚动优化协调微网购电和储能运行，以降低总购电成本，并减少预测误差带来的高价紧急购电支出。

项目来自数学建模竞赛团队的共同工作，核心思路为：

**LightGBM 滚动预测 → 历史残差 Q80 风险修正 → 48h 滚动优化 → 两阶段前瞻决策 → 实际运行结算与物理核验**

> 本仓库主要用于展示项目方法、核心代码与建模思路。  
> 原始赛事数据及部分运行输入未公开，因此当前公开版本不能直接完整复现论文全部实验。

---

## Highlights

- 使用 **LightGBM** 对负荷、光伏及电价进行滚动预测
- 基于历史预测残差构造 **Q80 风险修正**，降低净负荷低估造成的紧急购电风险
- 使用 **48h rolling horizon** 保留储能跨日价值，并按 24h / 6h 滚动执行
- 在日内多次更新预测的场景下构建 **两阶段前瞻模型**
- 对能量平衡、储能状态递推、功率边界、费用分解及求解精度进行系统核验

---

## 研究问题

预测更准确并不一定意味着购电成本最低。

当净负荷被低估时，微网可能需要以更高价格进行紧急购电；预测过高又会增加普通购电支出。同时，储能使当前时刻的决策影响后续多个时段，甚至跨越日期。

因此，本项目依次研究以下四类问题：

| 问题 | 信息条件 | 主要方法 |
|---|---|---|
| 第一问 | 日内负荷、光伏及电价已知 | 线性规划，联合优化购电与储能 |
| 第二问 | 使用历史数据预测负荷和光伏 | LightGBM + Q80 风险修正 + 48h 滚动优化 |
| 第三问 | 每日 0、6、12、18 点获得新信息 | 四时点滚动 + 三分支两阶段前瞻 |
| 第四问 | 电价也需要预测 | 滚动电价预测 + 动态购电优化 |

---

## 方法概述

### 1. LightGBM 滚动预测

分别对负荷和光伏发电进行预测，并使用：

- 日内时段特征
- 星期、节假日等日历特征
- 历史滞后值
- 滚动统计特征
- 季节周期特征

预测过程严格限制在决策时刻之前已经获得的信息，避免未来信息泄漏。

历史数据不足时，使用朴素预测完成冷启动。

---

### 2. Q80 风险修正

由于净负荷预测误差带来的经济损失具有明显的不对称性：

- **低估净负荷** → 可能触发高价紧急购电
- **高估净负荷** → 主要增加普通购电成本

因此，我们利用历史在线预测残差的 **80% 分位数** 对净负荷点预测进行修正，使购电策略适度向风险侧偏移。

Q80 在这里是一种基于历史误差的风险修正方法，并不代表 80% 的供电可靠性保证。

---

### 3. 滚动优化

第二问采用：

**48h 规划窗口 + 24h 实际执行**

每天根据新数据重新预测和优化，同时保持储能状态跨日连续。

第三问进一步在每日 0、6、12、18 点更新预测，并在 0、6、12 点构建下一次信息更新的代表情景，只执行当前决策后的前 6 小时。

---

### 4. 两阶段前瞻

在未来预测仍会更新的情况下，当前购电决策不仅需要考虑现有预测，还需要考虑：

> “未来获得新信息以后，我还可以重新调整计划。”

因此，第三问构建三分支两阶段前瞻模型，并通过非预见性约束保证新信息到来前各场景采取相同决策。

---

### 5. 物理与费用核验

项目在模型求解之外，还对运行结果进行了系统检查，包括：

- 电量平衡
- 储能 SOC 状态递推
- 充放电功率与容量边界
- 同时充放电检查
- 普通购电 / 调整 / 紧急购电费用分解
- 线性规划原始-对偶间隙及求解 gap

## 主要结果

以下结果来自团队论文及支撑材料中的正式实验。

| 实验 | 主要结果 |
|---|---|
| 第一问：确定性调度 | 单日购电费 **35,126.85 元**，较无储能方案下降 **26.90%** |
| 第二问：LightGBM 预测 | 净负荷 MAE **246.46 kW**，RMSE **361.97 kW**；相较前一周同刻基线分别下降 **24.81%**、**25.59%** |
| 第二问：Q80 风险修正 | 正式期总费用相较 point 基线下降 **8.30%**，紧急购电费下降 **78.62%** |
| 第三问：两阶段前瞻 | 相较四时点 Q80 滚动基准进一步节约 **62,138.91 元**，约 **0.4618%** |
| 第四问：动态电价 | 滚动调度方案相较日前方案总费用下降约 **1.99%** |

这些结果对应不同的信息条件和合同机制，不能直接将各问总费用横向比较为单一方法的效果。
